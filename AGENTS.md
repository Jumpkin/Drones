# Agent instructions

Read `PROJECT.md` before changing this repository.

Drones is an experimental web/API product with a native iOS test client,
deployed through the Tael platform.
Preserve these rules in every change:

- A routine Drones change modifies and deploys this repository only. Do not
  rebuild or deploy `hammerhead-ish/app-platform` unless shared routing,
  gateway, or host controls actually change.
- Use pull requests and the checked-in GitHub Actions workflows. Do not edit
  the application manually on the Hetzner server.
- On `main`, validate first, build and publish exactly one immutable image,
  verify that same digest, and deploy through the Drones-specific restricted
  SSH identity.
- Keep locked installs, tests, type checking, dependency audit, BuildKit cache,
  image scanning, non-root/read-only runtime assertions, health verification,
  strict SSH host-key checking, and automatic rollback.
- Every deployment attempt, including failures, must upload the 90-day
  `tael-deployment-log` JSON artifact generated by
  `scripts/write-deployment-log.sh`. Never include credentials, raw audio, or
  user data in it.
- Run `scripts/validate-deployment-contract.sh` before changing deployment
  files. CI must reject a workflow that removes this contract.
- The approved disposable test contract permits a product-private PostgreSQL
  database, anonymous device registration with non-secret device identifiers,
  session and detector metadata, and optional precise foreground GPS. It
  explicitly forbids raw-audio uploads and has no backups; do not expand that
  contract to customer authentication, valuable data, analytics, payments, or paid
  infrastructure without a new product decision.
- Preserve the product disclaimer: simulated distances are not field-validated
  operational detection ranges.

If `$tael-deploy-app` is installed, use it. These checked-in instructions are
the portable source for agents that cannot access the personal skill.
